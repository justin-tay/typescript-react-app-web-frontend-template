# Application Security Verification Standard (ASVS)

The OWASP ASVS control implementation for the web frontend maps against the [OWASP Application Security Verification Standard (ASVS) 5.0.0](https://github.com/OWASP/ASVS/tree/v5.0.0/5.0).
It is a planning and verification aid, not an ASVS conformance claim.

The control implementation covers the web frontend: a single-page application and its build tooling. It does not certify the backend, Keycloak, the page host, or the application an adopter builds from this template. Where a requirement is owned by one of those, the row says so (Delegated or Deployment responsibility) and records what the frontend does around it. The backend's own mapping is in its repository, `java-app-web-api-server-template`, in `docs/system-design/08-crosscutting-concepts/02-security-and-authentication/asvs.md`.

The tables contain all 345 ASVS 5.0.0 requirements. Requirement text is reproduced from OWASP ASVS 5.0.0, which is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Use version-qualified identifiers such as `v5.0.0-1.1.1` in evidence, tickets, and test cases so a later ASVS version can't silently change the requirement being referenced.

For the related evidence, see the [security concept](README.md), [Sessions](sessions.md) and [HTTP security headers](headers.md).
